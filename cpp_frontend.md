# Как построены компиляторы "под капотом"

Рекомендуется ознакомиться со статьёй [Компилятор EDG C/C++ превращён в открытый проект, развиваемый сообществом](https://www.opennet.ru/opennews/art.shtml?num=66397) by OpenNET.

Современные компиляторы C/C++ используют некоторое подмножество базовых технологий/компонентов, которые позволяют разработчиком пользовательских продуктов (компилятор + tooling) сфокироваться на тех задачах, которые они умеют делать лучше всего.

Имеет смысл написать, как минимум, о двух технологиях:

EDG C/C++ — это frontend, часть компилятора, которая занимается лексическим, синтаксическим и семантическим анализом исходного кода, построением промежуточного представления. Изначально продукт создавала компания Edison Design Group. Его долгое время использовали в ряде коммерческих компиляторов и инструментов: **Intel C++ Compiler**, **Microsoft Visual C++** (в том числе для IntelliSense), **NVIDIA CUDA Compiler**, Comeau C++,  SGI MIPSpro и Portland С/C++ других. В сентябре 2026 года исходный код EDG открыли, и теперь проект развивается сообществом под покровительством некоммерческой организации C++ Alliance.

LLVM — это инфраструктурный проект, который предоставляет набор инструментов и библиотек для создания компиляторов. Сам по себе LLVM не является компилятором: он даёт "движок" - бэкенд и промежуточные представления, а для конкретных языков (C, C++ и др.) к нему пишут отдельные фронтенды. Один из таких фронтендов — Clang.

LLVM использован в следующих продуктах:

= Apple Xcode — использует Clang/LLVM как основной компилятор для C/C++/Objective‑C/Swift; LLVM также задействован в оптимизациях и инструментах анализа
- Intel C++ Compiler (ICX) следующего поколения — построен на базе LLVM (в отличие от старого ICC на собственной инфраструктуре)
- Arm Compiler (для встраиваемых систем и HPC) — использует LLVM как основу для оптимизации и кодогенерации
- AMD Optimizing C/C++ Compiler — опирается на LLVM/Clang и собственные расширения

Установить clang в Debian/Ubuntu можно командой:

```shell
sudo apt install clang llvm lld
```

По используемым флагам компиляции Cland близок к GCC и в большинстве случаев можно использовать clang вместо gcc.
